# Get help with GenAIcode

- For installation instructions and examples, [read the documentation](https://github.com/gtanczyk/genaicode#readme).
- To find earlier answers, use the error message or the agent's name to [search open and closed issues](https://github.com/gtanczyk/genaicode/issues?q=is%3Aissue).
- If you still need help, describe what you're trying to do and where you're stuck. [Ask a question](https://github.com/gtanczyk/genaicode/issues/new?template=question.md).

## Report a bug

Include the steps that reproduce the problem, what you expected and what happened. Give your
operating system and GenAIcode version. You can find the version at the bottom of the desktop window's sidebar
or by running `genaicode --version`. GitHub issues are public, so remove credentials and private
project details from any logs or screenshots you share. [Open a bug report](https://github.com/gtanczyk/genaicode/issues/new?template=bug_report.md).
